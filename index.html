Contact Magic

Private performer notes for the Contacts-style magic app. Close this before handing the phone to a spectator.

Performance Flow

1. Arm performance mode

Single tap the Keypad tab. The Calls badge changes from 241 to 242, which is your silent cue that forced data is active.

2. Have them search three digits

The exact three digits show your configured Round 1 contacts. Their phone numbers update automatically so every result contains those digits.

3. Let them open one result

Their choice is locked. When you return to the list, read the initials down the top rows: first-name initials spell the chosen first name and last-name initials spell the last name.

4. Repeat or finish

The next three-digit search uses Round 2. When finished, double tap Keypad to restore the ordinary list and Calls badge.

Secret Controls

Optional tab peek

In Trick Setup, you can also make the bottom Contacts label change to the selected first name. Leave it off to use only the encoded top rows.

Setup Notes

Search rounds

Choose one to six results for each round and edit every first and last name. Round 1 starts with mostly female names; Round 2 starts with gender-neutral names. The defaults use visibly different name lengths to make fishing easier.

Optional detail overrides

For a three-digit search result, the app supplies a matching phone number, email, and birthday automatically. Pick fields can still add company, address, and notes. Magic Number remains available for contacts opened outside the three-digit routine.

Resetting

Use Reset Routine to return to Round 1 and clear the peek. Turning performance mode on also starts fresh.
